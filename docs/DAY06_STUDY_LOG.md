## 第一题与参考答案

先盖住答案预测：

```text
scores = [1,2,3,4]
values = [10,20,30,40]

完整结果 = softmax(scores) @ values
错误方法 = (第1块自己的输出 + 第2块自己的输出) / 2
分块方式：[1,2]与[3,4]
```

参考答案：完整结果约34.9265，错误简单平均约27.3106。
原因是每块自己归一化后再平均，会强行让两块各占一半总权重；
原本第二块分数更大，应获得更多总权重。

继续观察：m给出指数基准，l累积同一基准的分母，o累积同一基准的加权内容；
最大值变大时旧l/o一起乘 `exp(m_old-m_new)`，最后算o/l。
规范名称、发音及公式朗读见 [符号规范](NOTATION.md) 第4、7节。

## 收尾：把Day 6压成一张图

```text
最终目标：每个Query得到一个加权内容向量
    │
    ├─ 朴素路径：完整S → softmax得到完整P → P@V
    │
    └─ 分块路径：读一块K/V → 算局部分数 → 更新m/l/o
                                            ↓ 继续下一块
                                       所有块结束后o/l
```

| 量 | 保留什么 | 为什么需要 |
| --- | --- | --- |
| m | 已处理分数的最大值 | 给指数计算一个稳定基准 |
| l | 同一基准的指数和 | 保存跨块归一化的分母，不让每块都强占相同权重 |
| o | 同一基准的指数加权V和 | 保存最终输出的分子，通常是向量 |
| alpha | `exp(m_old-m_new)` | 旧l和旧o一起换到新基准 |

前两块示例的m从2变4，旧量乘 `exp(2-4)`：
因为 `exp(1-2)*exp(2-4)=exp(1-4)`，只是同一个权重换基准，
不是丢弃第一块。最终仍得到约34.9265。
